# Scalix World — Homebrew Tap

```bash
brew install scalixworld/tap/scalix-cloud
scalix-cloud login       # API key from https://console.scalix.world
```

Official Homebrew formulas for [Scalix Cloud](https://scalix.world) tools.

| Formula | What |
|---|---|
| `scalix-cloud` | The Scalix Cloud platform CLI (database, functions, AI, storage, run — one API key) |

Also available: `npm install -g scalix-cloud` (npm) · [docs.scalix.world/cli](https://docs.scalix.world/cli)
